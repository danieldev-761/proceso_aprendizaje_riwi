# Modelo de Datos – Proceso de Aprendizaje Riwi

Este repositorio contiene el diseño de la base de datos para modelar el proceso de aprendizaje de Riwi.

Se desarrollaron los siguientes artefactos:

* **Diagrama Entidad-Relación (DER):** representa las entidades, atributos y relaciones del sistema académico.
* **Modelo Relacional:** transformación del DER a un esquema relacional normalizado, incluyendo claves primarias y foráneas.

El modelo contempla la gestión de:

* Sedes y cohortes.
* Jornadas y salas.
* Clanes y Team Leaders (TL).
* Coders (estudiantes).
* Rutas de aprendizaje y módulos.
* Asignación de módulos a clanes.
* Seguimiento académico mediante notas por módulo y por ruta.
